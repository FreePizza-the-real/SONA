# SONA Privacy Policy

Last updated: November 20, 2026

SONA is a Windows desktop lyrics overlay.

## Information SONA accesses

SONA reads information from the active Windows media session, including:

- Track title
- Artist name
- Track duration
- Playback position and playback status

This information is used to identify the currently playing song and synchronize its lyrics.

## Information sent to third-party services

When searching for lyrics, SONA sends the track title, artist name, and available track duration to its configured lyrics providers:

- LiriQo
- LRCLIB

These services process requests according to their own policies and practices.

## Local storage

SONA stores application settings and a local lyrics cache on the user's computer.

The default storage directory is:

`%LOCALAPPDATA%\SONA-Lyrics\`

The directory may contain:

- `settings.json`
- `lyrics-cache.json`

## Accounts and credentials

SONA does not require users to sign into a SONA account or provide a Spotify API key.

## Analytics and tracking

SONA does not include a built-in analytics or advertising system.

## Data control

Users can remove SONA's locally stored settings and lyrics cache by deleting the `SONA-Lyrics` directory from their local application data folder.

## Contact

For questions about this policy, contact the SONA project owner through the project's GitHub repository.
